# Summary of Key EHR-Based Risk Prediction Models

| Model | Year | Data Used | Training Methodology & Architecture |
| ----- | ----- | ----- | ----- |
| **EHRMamba** | 2024 | MIMIC-IV & eICU Collaborative Research Databases | **Self-supervised pre-training + Prompted Fine-Tuning**: Built on Selective State Space Models (Mamba); pre-trained via Next Token Prediction (NTP) on longitudinal EHR sequences and fine-tuned using Multitask Prompted Finetuning (MPF). |
| **Med-BERT** | 2021 | Cerner Health Facts & Truven MarketScan (\~28 million electronic health records) | **Self-supervised pre-training + Supervised fine-tuning**: Pre-trained on structural disease/procedure code histories using modified MLM with domain-specific positional embeddings; fine-tuned for readmission and heart failure risk. |
| **CEHR-BERT** | 2021 | Large longitudinal structured administrative & clinical datasets (OMOP CDM format) | **Self-supervised pre-training + Supervised fine-tuning**: Pre-trained using masked language modeling on standardized OMOP Common Data Model sequences, incorporating explicit temporal, visit type, and age embeddings. |
| **Hi-BEHRT** | 2021 | CPRD & HES databases (longitudinal patient trajectories over extended timeframes) | **Self-supervised pre-training + Supervised fine-tuning**: Hierarchical Transformer architecture designed to handle extremely long histories by separating visit-level multi-head self-attention from patient-level trajectory modeling. |
| **BEHRT** | 2020 | UK CPRD linked with HES (\~1.6 million primary/secondary care patient records) | **Self-supervised pre-training + Supervised fine-tuning**: Adapted transformer architecture (BERT) trained using Masked Language Modeling (MLM) on temporal code sequences; fine-tuned for multi-label downstream disease prediction. |
| **ClinicalBERT** | 2019 | MIMIC-III database (\~2.0 million unstructured clinical notes) | **Self-supervised pre-training + Supervised fine-tuning**: Pre-trained on domain-specific unstructured clinical narratives using bidirectional transformer (BERT) objectives; fine-tuned for 30-day hospital readmission risk. |
| **Deepr** | 2016 | Large longitudinal hospital dataset (structured inpatient administrative/clinical records) | **Supervised End-to-End**: Convolutional Neural Network (CNN) architecture operating over mapped diagnosis and medication sequences, using explicit delimiter tokens for variable inter-visit duration. |
| **Doctor AI** | 2016 | Sutter Health EHR database (\~260,000 longitudinal patient records over multi-year spans) | **Supervised End-to-End**: Multi-layer Gated Recurrent Unit (GRU) recurrent network trained directly to predict both future disease codes and time intervals to the next visit. |
| **RETAIN** | 2016 | Sutter Health EHR database (\~14 million visits, focused on heart failure cohorts) | **Supervised End-to-End**: Reverse-time attention mechanism built on two-level recurrent neural networks (RNNs/GRUs); trained directly on target labels (e.g., heart failure onset) to provide clinical interpretability. |
